# Local Scratch

A small, dependency-free Scratch-inspired programming playground that runs entirely in the browser.

## Run locally

From this directory, start any static file server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Drag blocks from the palette into the code area, click **Run**, and use **Save**/**Load** to persist a project in browser storage.
